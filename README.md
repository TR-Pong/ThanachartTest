# แบบทดสอบ

โปรเจกต์ตัวอย่างระบบแสดงสินค้า ตะกร้าสินค้า และ Checkout เพื่อตัดจำนวนสินค้าใน PostgreSQL

## เทคโนโลยีท่ีใช้

- **Frontend:** Next.js, TypeScript, Tailwind CSS, Zustand(cart system),toast(shadcn)
- **Backend:** ASP.NET , Entity Framework Core, Npgsql
- **Database:** PostgreSQL ผ่าน Docker Compose

## 2. โครงสร้างโปรเจกต์

```text
TanachatTest/
├── BE/                   # BackEnd
├── FE/                   # FrontEnd
├── docker-compose.yml    # PostgreSQL
├── tanachat_db.sql       # Database backup
└── README.md
```
